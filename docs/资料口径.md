# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

slot_id是人/日期/餐次的稳定需求，order_changes按effective排序，修订不增餐。厨房cutoff_at之后取消仍收内部服务费，服务费每份20元；制作、配送与实际领取数量不由收费推断。portion_id为同一份餐的身份，ward_receipt与person_receipt均引用同份，只算一次服务；serving认可个人回执或有explicit代理关系的回执，单病区收餐不证明个人吃到。锅次产出包含未送和staff份，退回成品只能discard不还原料。原料实耗=issue-return，按pot_product中实际产出份数×该餐种在该食材的配方克数分担，分母包括未送品及职工餐。锅次缺物料证据时成本未决但服务可确认。

## meal_slots
稳定需求。

记录键：['slot_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| slot_id | string | 槽 |
| person | string | 人 |
| meal_at | datetime | 餐次 |
| original_ward | string | 病区 |

| 字段 | 类型 | 含义 |

## receipts
独立层级证据。

记录键：['receipt_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| receipt_id | string | 回执 |

| party | string | 主体 |
| at | datetime | 时点 |

同一来源记录键的新文件表示整行修订，调用者明确接收次序；原始文件和接收历史须保留。相同文件摘要不增加事实。下面标为后续接收的文件不随基础资料自动生效，用户可分次装载。历史事实的业务时点与本次接收时点分开。金额除另述外人民币元，结算舍入到分的尾差归该账单分摊基数最大项，并列按业务键升序。本文规定来源语义，不规定待开发仓表、算法或架构。
